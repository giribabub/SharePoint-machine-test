Problem

Roy wants to change his profile picture on Facebook. Now Facebook has some restriction over the dimension of picture that we can upload.

Minimum dimension of the picture can be L x L, where L is the length of the side of square.

Roy has N photos of various dimensions. Dimension of a photo is denoted as W x H, where W is width and H is height.

Rules
  1. If any of the width or height is less than L, print UPLOAD ANOTHER.
  2. If width and height are both large enough:
    • If the photo is already square, print ACCEPTED.
    • Otherwise print CROP IT.
Sample Input L = 180 N = 3 Photo 1: W = 640, H = 480 Photo 2: W = 120, H = 300 Photo 3: W = 180, H = 180 Sample Output CROP IT UPLOAD ANOTHER ACCEPTED
